# Rust 学习与实践建议

## 编码习惯

- 默认使用不可变变量，必要时再加 `mut`。
- 函数参数能借用就借用，不要随意取得所有权。
- 错误用 `Result` 表达，缺失值用 `Option` 表达。
- 公共 API 的错误类型要清晰，不要让调用方只能拿到字符串。
- 优先写小函数，让所有权关系更容易看清。

## 工程习惯

- 使用 `cargo check` 高频反馈类型和借用问题。
- 使用 `cargo test` 验证示例和核心行为。
- 使用 `cargo fmt` 保持格式一致。
- 模块按职责划分，而不是把所有代码堆在 `main.rs`。

## 学习方法

- 主动制造编译错误，阅读并理解错误信息。
- 对照 Java / Go 的经验，但不要强行套用 OOP 或 goroutine 思维。
- 所有权、生命周期和 trait 是 Rust 的主线，其他语法都服务于这条主线。
